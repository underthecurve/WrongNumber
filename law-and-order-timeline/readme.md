# Law & Order timeline analysis

## DATA
All data in [this Google sheet](https://docs.google.com/spreadsheets/d/1Kx3jrh44nrAW4jhUkGhZAOQrtEzCqaCL_u3YwtJEWDI/edit).

- `episode_links`: Fandom Wiki links to each Law & Order episode (up to Season 25, Episode 12)
- `missing_cards`: Episodes that are missing scene cards
- `scene_cards_data`: Cleaned data on the episode scene cards for every episode that has one
- `first_final_scene_cards`: First and final scene cards for each episode
- `tribble314_data`: Cleaned version of [this sheet created by Tribble314](https://www.thecomicboard.com/threads/law-order-timeline.14797/) on The Comic Board forum 

## SCRIPTS

- `part_one_analysis.R`: Analysis for the Part One section of my post, using the Fandom Wiki scene cards
- `part_two_analysis.R`: Analysis for the Part One section of my post, using the Fandom Wiki scene cards in conjuction with the Tribble314 data
